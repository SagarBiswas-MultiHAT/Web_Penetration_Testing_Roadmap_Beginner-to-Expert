# Contributing to Web Penetration Testing Roadmap

First off, **thank you** for considering contributing! 🎉 This roadmap is a community-driven, living document — your input makes it better for everyone learning penetration testing.

## 🚀 Quick Ways to Contribute

### 1. Suggest a New Resource
Found a great TryHackMe room, YouTube channel, or tool? [Open an issue](../../issues/new?template=resource-suggestion.md) with:
- The resource name and link
- Which section/phase it belongs to
- A brief description of why it's valuable

### 2. Report a Broken or Paywalled Link
TryHackMe rooms change pricing frequently. If you find a link that's broken or no longer free, [report it here](../../issues/new?template=broken-link-report.md).

### 3. Share Your Learning Journey
Completed (or partially completed) this roadmap? We'd love to hear about your experience:
- How long each phase took you
- What worked well vs. what was confusing
- Resources you wish were included

[Open a discussion](../../discussions) in the **🏆 Show & Tell** category.

### 4. Fix Typos or Improve Clarity
Small improvements matter! Feel free to submit a PR directly for:
- Typo fixes
- Grammar improvements
- Better explanations of concepts
- Formatting improvements

### 5. Add a Tool to the Tools Directory
To add a tool to `resources/tools-directory.md`, follow this table format:

```markdown
| [Tool Name](https://github.com/link) | **Language** | `Platform Support` | Brief description. |
```

### 6. Translate a Section
We welcome translations! To translate:
1. Create a folder: `translations/<language-code>/` (e.g., `translations/es/`)
2. Translate the target file(s)
3. Submit a PR with the translation

## 📋 Contribution Guidelines

### For Issues
- Search existing issues before creating a new one
- Use the provided issue templates
- Be specific — include links, screenshots, or examples where possible

### For Pull Requests
1. **Fork** the repository
2. Create a **feature branch** (`git checkout -b add-new-resource`)
3. Make your changes
4. **Test** that all links work
5. Submit a **PR** with a clear description of what you changed and why

### Content Standards
- All resources should be **free** or have a clearly marked free tier
- External links must be to **reputable, maintained** sources
- Tools listed should be **actively maintained** (recent commits within the last year)
- Follow the existing formatting style of the section you're editing
- Use clear, beginner-friendly language

### What We're NOT Looking For
- Paid course promotions or affiliate links
- Content that encourages illegal activity
- Duplicate resources already covered in the roadmap
- AI-generated filler content without genuine curation
