# Week 09 — OWASP Top 10 Part 2: Design Flaws & Misconfigurations

[⬅ Back to Roadmap 2](../roadmaps/roadmap-2-practical-labs.md)

## 🎯 Learning Objectives
Master the second half of the OWASP Top 10 vulnerabilities, focusing on structural application flaws, misconfigurations, and software integrity issues.

## 📖 Key Topics
1. **Insecure Design (A04:2021)**: Flawed architecture, business logic flaws, missing security controls.
2. **Security Misconfiguration (A05:2021)**: Default passwords, enabled debug modes, missing security headers.
3. **Vulnerable and Outdated Components (A06:2021)**: Known CVEs in dependencies, software supply chain risks.
4. **Identification & Authentication Failures (A07:2021)**: Credential stuffing, weak password policies, session hijacking.
