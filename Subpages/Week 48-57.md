# Week 48-57 — Advanced Server-Side Vulnerabilities & Exploit Crafting

[⬅ Back to Roadmap 2](../roadmaps/roadmap-2-practical-labs.md)

## 🎯 Learning Objectives
Master complex, high-impact server-side vulnerabilities and advanced exploit development techniques over a 10-week intensive sprint.

## 📖 Weekly Curriculum Breakdown
- **Week 48**: Server-Side Request Forgery (SSRF) — Blind SSRF, out-of-band interaction, internal network pivots.
- **Week 49**: Server-Side Template Injection (SSTI) — Jinja2, Twig, ERB, FreeMarker payload construction & RCE.
- **Week 50**: Insecure Deserialization — Java, PHP, Python pickle gadget chains and ysoserial payload generation.
- **Week 51**: XML External Entity (XXE) Injection — Blind XXE, out-of-band data exfiltration, XInclude attacks.
- **Week 52**: HTTP Request Smuggling — CL.TE, TE.CL, TE.TE vulnerabilities, front-end vs back-end parsing discrepancies.
- **Week 53**: HTTP/2 Request Smuggling — H2.CL, H2.TE downgrading attacks, request splitting.
- **Week 54**: OAuth 2.0 & Authentication Flaws — Redirect URI hijacking, implicit grant abuse, secret key exposure.
- **Week 55**: JWT Vulnerabilities — None algorithm, weak HMAC secrets, jku/x5u header injection.
- **Week 56**: GraphQL & API Vulnerabilities — Introspection leaks, batching attacks, IDOR in GraphQL nodes.
- **Week 57**: Web Cache Poisoning & Deception — Unkeyed inputs, unkeyed headers, cache key manipulation.
