# Week 39-45 — Client-Side Web Vulnerabilities Mastery

[⬅ Back to Roadmap 2](../roadmaps/roadmap-2-practical-labs.md)

## 🎯 Learning Objectives
Master client-side application attacks by deep-diving into PortSwigger Web Security Academy modules over a 7-week period (1 vulnerability class per week).

## 📖 Weekly Curriculum Breakdown
- **Week 39**: Cross-Site Scripting (XSS) — Reflected, Stored, DOM-based, context bypasses.
- **Week 40**: Cross-Site Request Forgery (CSRF) — Token bypasses, SameSite cookie quirks.
- **Week 41**: Cross-Origin Resource Sharing (CORS) — Misconfigurations, wildcard origins, null origin.
- **Week 42**: Clickjacking — UI redressing, framebusting bypasses, CSP frame-ancestors.
- **Week 43**: DOM-based Vulnerabilities — DOM Clobbering, open redirection, web message manipulation.
- **Week 44**: WebSockets Security — Cross-site WebSocket hijacking, unencrypted ws:// channels.
- **Week 45**: Prototype Pollution — Client-side gadget chains, object property overrides.

## 🧪 Practice & Platform Target
- **Platform**: [PortSwigger Web Security Academy](https://portswigger.net/web-security)
- Complete all **Apprentice** and **Practitioner** labs for each topic.
- (Optional) Attempt **Expert** labs for advanced bypasses.
