# Week 58-60 — Methodology Standardization & Final Capstone

[⬅ Back to Roadmap 2](../roadmaps/roadmap-2-practical-labs.md)

## 🎯 Learning Objectives
Standardize your penetration testing methodology using the OWASP Web Security Testing Guide (WSTG v4.2) and execute a full professional capstone engagement.

## 📖 Key Activities
1. **OWASP WSTG Deep-Dive**: Study the standard testing methodology across Information Gathering, Configuration, Identity Management, Authentication, Authorization, Session Management, Input Validation, Error Handling, Cryptography, Business Logic, and Client-Side testing.
2. **Professional Reporting Practice**: Prepare executive summaries, risk rating matrix (CVSS v3.1/v4.0), technical finding write-ups, and proof-of-concept exploit steps.
3. **Capstone Engagement**: Perform a complete white-box or black-box assessment on a complex lab environment (OWASP Juice Shop, HackTheBox, or Proving Grounds).

## 📚 Essential Reading
- [OWASP Web Security Testing Guide (WSTG)](https://owasp.org/www-project-web-security-testing-guide/stable/)
- [CVSS v3.1 Specification & Calculator](https://www.first.org/cvss/v3.1/specification-document)
- [PTES (Penetration Testing Execution Standard)](http://www.pentest-standard.org/)
