# Week 08 — OWASP Top 10 Part 1: Injection & Broken Auth

[⬅ Back to Roadmap 2](../roadmaps/roadmap-2-practical-labs.md)

## 🎯 Learning Objectives
Deep-dive into the foundational vulnerabilities of the OWASP Top 10, focusing on Injection flaws and Authentication failures.

## 📖 Key Topics
1. **Broken Access Control (A01:2021)**: IDOR, privilege escalation, path traversal.
2. **Cryptographic Failures (A02:2021)**: Sensitive data exposure, weak algorithms, hardcoded secrets.
3. **Injection (A03:2021)**: SQLi, Command Injection, LDAP Injection, SSTI.
